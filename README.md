# 海内集团 CinaGroup Brand

海内集团官方通用品牌资产仓库。当前集团标准为 **v2.1.1 传承中文 + Geist 英文**：保留原始左侧图案、蓝色渐变与中文字形，英文 CINAGROUP 使用 **Geist Regular** 轮廓，尖角采用主笔画宽度 **50%** 的圆角半径，**N 字上下内侧的两处锐角保留原状**。中英双行组合等宽、左右对齐，蓝色底板采用边长 **4.6875%** 的等比例圆角。
