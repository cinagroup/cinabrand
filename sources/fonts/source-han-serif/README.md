# 思源宋体 / Source Han Serif SC

Unmodified **Source Han Serif SC Regular 2.003** (Simplified Chinese) from Adobe's official [2.003R release](https://github.com/adobe-fonts/source-han-serif/releases/tag/2.003R).

- File: [`OTF/SimplifiedChinese/SourceHanSerifSC-Regular.otf`](https://github.com/adobe-fonts/source-han-serif/blob/2.003R/OTF/SimplifiedChinese/SourceHanSerifSC-Regular.otf), 24,543,332 bytes.
- SHA-256: `78aa7a328fd974df2d688c8a9fd74a33d8334dfa84ab24d9d11efb2ffc464117`.
- Official Git blob SHA-1: `cb41635674be23029e98469f729eded6ebc54611`; checked against the downloaded binary before copying it here.
- License: [SIL Open Font License 1.1](OFL.txt), copied unchanged from the [same release](https://github.com/adobe-fonts/source-han-serif/blob/2.003R/LICENSE.txt).
- The copyright notice and reserved font names are preserved in that license and the original font binary.

`scripts/songti-wordmark.mjs` and `scripts/font-wordmark.mjs` extract only `海内` from the Simplified Chinese face. Original glyph outlines, advances and kerning are preserved at 1000 units/em, then the whole wordmark is scaled proportionally. No synthetic bold, horizontal stretch, subsetting, or font modification is applied. The visible bounds are `37 -837 1902 916`, with glyph IDs `23386` and `10949`.

The SVG wordmarks use fixed vector paths and do not need the font installed. The original font is included unchanged for reproducibility, with its OFL license. Combined SVGs embed the approved full-color symbol bitmap; standalone Songti wordmark SVGs are entirely vector. The circled registration symbol continues to use the separately pinned Geist font.
